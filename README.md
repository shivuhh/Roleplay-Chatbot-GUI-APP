# Roleplay-Chatbot-GUI-APP
After Character AI went into a freemium model it has become almost impossible to use their app without getting an add every 20 seconds. Which is why I decided to spend 5 dollars and alongside Kimi3.1 pro built an app that can be used to talk to your own models and role-play with them. It has all the basic functions like saving, loading and regenerating messages and such as well as editing the message sent by the bot. Please feel free to improve it as much as you want and I'd like to see what the geniuses here can do with it. This is mainly a fun project, and currently as it is is functional for what it is, although it could ue some polishing.
